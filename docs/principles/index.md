# Principles

The durable properties the tool is built on. Each stays true even as the implementation changes.

- [Local processing](local-processing.md) – all work happens in the browser; no server and no uploads.
- [Untrusted bundles](untrusted-bundles.md) – bundles are treated as untrusted input, with defense in depth.
- [Link-driven discovery](link-driven-discovery.md) – the bundle describes itself through links from an entry point; there is no manifest.
