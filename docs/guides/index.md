# User guides

Task-oriented guides for using okfy to read a bundle. They follow the path
from opening a bundle to reading and collecting pages. The same controls are
documented as reference under [Interface](../interface/index.md).

- [Getting started](getting-started.md) – open a bundle, orient in the graph and read your first concept.
- [Explore the graph](explore-the-graph.md) – pan, zoom, inspect nodes and move through directories.
- [Find a concept](find-a-concept.md) – narrow the graph with search, filters and the legend.
- [Read a concept](read-a-concept.md) – open a page, follow links and footnotes, and page back and forward.
- [Controls](controls.md) – the mouse, touch, keyboard and toolbar controls in one place.
- [Troubleshooting](troubleshooting.md) – what to check when a bundle or a page does not load.
- [Install okfy as a web app](install-as-web-app.md) – install okfy as a progressive web app on a computer, Android or iOS.

## Collecting pages
