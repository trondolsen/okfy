# Interface

How a user points the tool at a bundle, and how a bundle is delivered.

- [URL parameters](url-parameters.md) – `bundle`, `start` and `depth`.
- [Languages](languages.md) – the interface translations, language selection and writing direction.
- [Assistant](assistant.md) – the optional in-page AI agent that chats about the bundle through a provider you configure.
- [Runtime directory](runtime.md) – the synthetic `.runtime` directory that shows the viewer's own state.
- [Local folders](local-folders.md) – opening a folder or dropping one on the window.
- [File, image and media preview](file-preview.md) – how non-Markdown files are shown, including images, audio and video.
- [Build a deck of cards](deck.md) – collect pages into a right-edge deck and add guides as sub-decks.
- [Declared decks](declared-decks.md) – how each page declares its deck membership, built when the bundle loads.
- [Publishing](publishing.md) – serving a bundle on a website.
- [Installable web app](installable-web-app.md) – the manifest and service worker that let okfy run as an installed app.
- [Link previews](link-previews.md) – the Open Graph tags that fill the preview card when okfy is shared (for example on Mastodon).
