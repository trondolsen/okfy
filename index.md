# okfy – knowledge bundle

This directory tree is the project's **OKF v0.2 bundle**. It explains what the okfy is, how it works and how to use it, as a set of linked concept files under `docs/`. The tool reads this same format, so the bundle doubles as a browsable example.

## Start here

- [About this bundle](docs/about-this-bundle.md) – the OKF version, the OKF Praxis extension, scope and provenance.

## Guides

- [User guides](docs/guides/index.md) – task-oriented guides for getting started, exploring, searching, reading and troubleshooting.

## Principles

- [Principles](docs/principles/index.md) – the durable properties the tool is built on: local processing, untrusted bundles and link-driven discovery.

## Model

- [Model](docs/model/index.md) – how an OKF bundle and its concepts map to the graph the tool draws.

## Algorithms

- [Algorithms](docs/algorithms/index.md) – crawling, graph construction, force-directed layout and the Markdown renderer.

## Interface

- [Interface](docs/interface/index.md) – URL parameters, local folders and publishing.

## Design

- [Design](docs/design/index.md) – the visual language: theme, layout, components and accessibility cues.

## Security

- [Security](docs/security/index.md) – request bounds, resource lifecycle, limits and residual risk.

## Compliance

- [Compliance](docs/compliance/index.md) – how okfy relates to the rules for AI systems, including AI transparency.

## Maintenance

- [Maintenance](docs/maintenance/index.md) – the test suite and where the knowledge comes from.

## DevOps

- [DevOps](docs/devops/index.md) – release and runtime controls: the feature toggles compiled into a copy.

## Reviews

- [Reviews](docs/reviews/index.md) – dated review documents from the development cycle.

## Scope

Only `index.md` at the bundle root and the files under `docs/` are concepts or reserved index files. `README.md`, `test/**/*.md` and other project documents keep their original form and are not part of the knowledge model. Links in this bundle are relative, so the explorer can follow them.
